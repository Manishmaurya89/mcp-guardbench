# Sample report

Generated by a real run of the demo:

```bash
guardbench init-db
guardbench seed-demo
guardbench benchmark run --project demo --cases test_cases/ \
    --adapter no-defense-baseline --adapter reference-static --adapter reference-runtime \
    --output reports/sample --format json --format markdown --format csv
```

**These results were obtained from local reference fixtures shipped with this repository.** They
describe only the `no-defense-baseline`, `reference-static`, and `reference-runtime` adapters, against
the 9 test cases in `test_cases/`, under the default policy — not any real MCP server. See
[`../../docs/limitations.md`](../../docs/limitations.md) before drawing conclusions from these numbers.

* [`report.md`](report.md) — the full Markdown report (configuration, per-case results, metrics,
  findings, reproducibility metadata).
* [`report.json`](report.json) — the same report as structured data.
* [`summary.csv`](summary.csv) — the metrics table only, for spreadsheets.

Regenerate this directory any time with `make demo && make report`, or the commands above. Every value
here is reproducible from the recorded `seed`, `policy_sha256`, and `test_corpus_sha256` in the report's
"Reproducibility" section (latency and timestamps will differ between runs; verdicts will not).
